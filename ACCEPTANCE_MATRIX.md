# Delivery acceptance matrix

This matrix adapts the web-oriented design to a native macOS app. New session imports create a separate session; Add cards appends additional Unreviewed entries to the open session. AI revision prompts include only Needs adjustment cards and request only those revised cards to review separately, without matching or merging. An independent reviewer completed the original baseline runtime checks described below. External Anki app verification is skipped at the user's request.
